# Contributing

Thanks for contributing to ExpiryShield AI.

## Development

1. Fork the repository.
2. Create a feature branch.
3. Run `npm install`.
4. Add your changes.
5. Test the application locally.
6. Open a pull request.

## Pull requests

Please explain:

- What changed.
- Why it changed.
- How it was tested.
- Whether the change affects privacy or API usage.
